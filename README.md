## How I build

**Start with the decision.** Define the user, constraints, and economics before the architecture.<br>
**Keep the evidence.** Preserve provenance, corrections, and unknowns.<br>
**Design the recovery.** Bound retries, make authority explicit, and keep state durable.<br>
**Make the work inspectable.** Ship runnable demos, clear limitations, and reproducible checks.

Also building **[Universal Engineering Agent](https://github.com/MajidAsghariTabrizi/universal-engineering-agent)**: a vendor-independent reference kernel for inspecting, planning, verifying, and recovering engineering work.
